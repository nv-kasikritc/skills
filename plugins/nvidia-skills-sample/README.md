# NVIDIA Skills Sample

A small, working [Agent Plugins 1.0.0](https://agent-plugins.org/specification)
package that bundles the existing NVIDIA Skill Finder. Ask an agent which
NVIDIA skill fits a workflow; the finder checks the live catalog and returns a
recommendation, an install command, and a first useful prompt. Installing a
recommended skill remains a separate action that requires user approval.

This is an example package maintained in a fork. Its metadata is attributed to
the sample's packager; the bundled skill retains NVIDIA's original attribution,
license, and content. The existing production plugin is
[`nvidia-skills`](https://github.com/NVIDIA/skills/tree/main/plugins/nvidia-skills).

## Package layout

```text
nvidia-skills-sample/
├── plugin.json                 # Portable Agent Plugins 1.0.0 manifest
├── skills/
│   └── nvidia-skill-finder/
│       ├── SKILL.md             # Agent Skills metadata and instructions
│       └── references/          # Bundled routing and client guidance
├── .claude-plugin/plugin.json   # Generated client-specific compatibility manifest
├── .codex-plugin/plugin.json    # Generated client-specific compatibility manifest
├── .cursor-plugin/plugin.json   # Generated client-specific compatibility manifest
└── README.md
```

The skill directory also includes its original evaluation, provenance, and
agent metadata files. All bundled skill files are copied from
[`skills/nvidia-skill-finder/`](https://github.com/NVIDIA/skills/tree/main/skills/nvidia-skill-finder); edit the
catalog's source definition rather than the generated copy.

The portable manifest declares the canonical schema:

```json
{
  "$schema": "https://agent-plugins.org/schemas/1.0.0/plugin.schema.json",
  "name": "nvidia-skills-sample",
  "version": "0.1.0"
}
```

The actual [`plugin.json`](plugin.json) adds description, author, repository,
homepage, license, and keywords. Skills are discovered from the fixed `skills/`
location; a `skills` field does not belong in the portable manifest. This
sample uses only the skills component. An MCP component, if needed later,
belongs in a root `mcp.json` targeting the same specification version.

The client-specific manifests are additional compatibility files generated by
this repository's existing tooling. The portable package is loaded through
the root `plugin.json`. Its skill files remain inside the plugin root, so the
whole directory can be copied to another location without the catalog checkout.

## Try the sample

1. Clone this fork's sample branch:

   ```sh
   git clone --branch sample/agent-plugins --single-branch https://github.com/nv-kasikritc/skills.git
   cd skills
   ```

2. Load the `plugins/nvidia-skills-sample/` directory in a
   [compatible client](https://agent-plugins.org/compatible-clients) that supports skills.
   Installation and enablement are client-specific; the standard does not
   define a universal install command. For a client that supports loading a
   local Claude Code plugin directory, for example:

   ```sh
   claude --plugin-dir ./plugins/nvidia-skills-sample
   ```

3. Ask:

   > Which NVIDIA skills can help with simulation and robotics?

   The finder should consult the live NVIDIA catalog, recommend relevant
   skills, and provide install commands and first prompts. It should ask before
   installing a recommendation.

Loading this package needs no NVIDIA GPU, API key, or MCP server. The finder
uses network access to consult the live catalog. Its lookup mechanism depends
on the active client; the bundled skill documents CLI, web, and Hermes paths.

## Rebuild and customize

The hand-maintained package definition is
[`plugins.d/nvidia-skills-sample.yml`](https://github.com/nv-kasikritc/skills/blob/sample/agent-plugins/plugins.d/nvidia-skills-sample.yml).
The shared defaults and generator are described in
[`plugins.d/README.md`](https://github.com/nv-kasikritc/skills/blob/sample/agent-plugins/plugins.d/README.md).

From the repository root, build all plugin packages:

```sh
python3 -m venv /tmp/nvidia-plugin-venv
/tmp/nvidia-plugin-venv/bin/python -m pip install pyyaml
/tmp/nvidia-plugin-venv/bin/python .github/scripts/build-plugins.py
```

To make another sample, copy the YAML definition, give it a new `name` matching
the filename, update its metadata, and choose existing catalog entries in
`include_skills`. Keep `skill_files: copy` for a self-contained portable
package. The three `marketplace_enabled` flags are deliberately `false` so
this example does not become an official marketplace listing.

Commit the YAML and generated package together. This README is hand-maintained
and preserved by the generator. After committing, check for build drift:

```sh
/tmp/nvidia-plugin-venv/bin/python .github/scripts/build-plugins.py --check
```

## Validate the standard format

Download the published schema explicitly for author-time validation. A client
uses its supported local schema contract when loading the plugin; the manifest
does not instruct the client to fetch a schema at runtime.

From the repository root:

```sh
/tmp/nvidia-plugin-venv/bin/python -m pip install jsonschema 'skills-ref==0.1.1'
curl --fail --location https://agent-plugins.org/schemas/1.0.0/plugin.schema.json \
  --output /tmp/agent-plugin-1.0.0.schema.json
/tmp/nvidia-plugin-venv/bin/python - <<'PY'
import json
from pathlib import Path
from jsonschema import Draft202012Validator

schema = json.loads(Path("/tmp/agent-plugin-1.0.0.schema.json").read_text())
manifest = json.loads(Path("plugins/nvidia-skills-sample/plugin.json").read_text())
Draft202012Validator.check_schema(schema)
Draft202012Validator(schema).validate(manifest)
print("Agent Plugins 1.0.0 manifest is valid")
PY
/tmp/nvidia-plugin-venv/bin/agentskills validate \
  plugins/nvidia-skills-sample/skills/nvidia-skill-finder
```

Schema validation checks the manifest; the `agentskills` CLI provided by
`skills-ref` checks the bundled skill's frontmatter and naming. Also check that every package path resolves within the
plugin root before distribution. Runtime behavior depends on the selected
client and access to the live NVIDIA catalog.
